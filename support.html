Nothing is showing up

  1. Open Shortcuts › Automation and check there’s a Notification automation for the app, set to Run Immediately.
  2. Check its action is Unclaimed › File Notification, with Title, Subtitle and Message set to the parts of the Notification variable.
  3. In Unclaimed, tap the bell and use Send a test notification (add an automation for Unclaimed itself first).

Can it recover notifications from before I installed it?

No. iOS only passes notifications to the automation as they arrive. Capture starts when you set it up.

Does it know if I opened or dismissed something?

No. iOS doesn’t share that. Every tag arrives “waiting” and is stamped claimed when you look at it in Unclaimed, or when you swipe to claim it.

Some text is missing

If an app hides previews, or your Lock Screen previews are off, iOS may pass less text to the automation. Pictures and attachments aren’t passed at all.

Restoring the lifetime unlock

Settings › Membership › Unlock lifetime › Restore purchase, using the same Apple Account. Family Sharing is supported.
